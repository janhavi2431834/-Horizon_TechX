## 🖼️ 1. Image Gallery
`gallery.html`

A minimal, editorial-style photo gallery with a masonry layout and a full-screen lightbox viewer.

**✨ Features**
- 🧩 Masonry-style responsive grid (auto-adjusts to 1–3 columns based on screen size)
- 🏷️ Category filters — **Terrain**, **Structure**, **Street** — with an "All" view
- 🔍 Click-to-zoom **lightbox** with smooth fade/scale transitions
- ⬅️➡️ Navigate images with on-screen arrows **or** keyboard (`←` `→`)
- ⌨️ Close lightbox with `Esc` or the ✕ button
- 🎭 Hover effects — image zoom + caption reveal with gradient overlay
- 📱 Fully responsive — collapses to a single column on mobile
- 🅰️ Custom typography pairing (Newsreader serif + Inter sans-serif)

**🛠️ Built with:** HTML5, CSS Grid/Columns, vanilla JavaScript
**🌐 Note:** Images load from Lorem Picsum — internet connection required.

## 🧮 2. Calculator
`calculator.html`

A hardware-inspired calculator with a tactile, retro-device look and a full working expression engine.

**✨ Features**
- ➕➖✖️➗ All core arithmetic operations, plus **%** and backspace
- 🖥️ Two-line display — running expression on top, live result below
- ⌨️ Full **keyboard support** (numbers, operators, `Enter`, `Backspace`, `Esc`)
- 🔁 Chained expressions (e.g. `12 + 8 × 3 =`) evaluated safely
- 🧹 Clear (`AC`) and single-character backspace (`⌫`)
- 🎛️ Tactile button press animations with depth/shadow effects
- 📱 Responsive layout that scales down for small screens

**🛠️ Built with:** HTML5, CSS3 (custom properties, gradients, shadows), vanilla JavaScript
**🎨 Design:** Dark "hardware rig" theme with warm ember accents

## 🎵 3. Music Player
`musicplayer.html`

A playlist-driven audio player styled to match the calculator's dark, hardware-inspired aesthetic.

**✨ Features**
- ▶️⏸️ Play / Pause with animated icon swap
- ⏭️⏮️ Next / Previous track controls
- 🎚️ Draggable **progress bar** with click-to-seek and live time display
- 🔊 Volume slider control
- 🔁 **Autoplay toggle** — auto-advances to the next track when one ends
- 📃 Clickable **playlist** showing track title, artist & duration
- 🖼️ Album art per track, highlighted "now playing" row
- ⌨️ Keyboard shortcuts — `Space` to play/pause, `←` `→` to skip tracks
- 📱 Fully responsive card layout

**🛠️ Built with:** HTML5 `<audio>` API, CSS3, vanilla JavaScript
**🌐 Note:** Uses SoundHelix demo tracks + Picsum album art — internet connection required.

## 🎨 Design Language

All three projects share a consistent **dark, hardware-inspired visual identity** — deep stone tones, warm ember-orange accents, and monospace/geometric type pairings — so they feel like one cohesive set rather than three disconnected pages.
